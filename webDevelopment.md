# Web Development Guidelince

To development web app we have to follow certain strectural guidelince. It makes web development consistancy, easy and reasultable. All necessary guidelinces for web development are listed in this file.

## Project Details

What packages and services are used for web app development?

1. Dependencies
   a. express : Fast, unopinionated, minimalist web framework for Node.js.
   `npm i express`
   b. dotenv : Dotenv is a zero-dependency module that loads environment variables from a .env file into process.env. Storing configuration in the environment separate from code is based on The Twelve-Factor App methodology.
   `npm i dotenv`
   c. mongoose : `npm i mongoose`
   d. zod : Zod is a TypeScript-first validation library. Define a schema and parse some data with it. You'll get back a strongly typed, validated result.
   `npm i zod`
   e. multer : Multer is a node.js middleware for handling multipart/form-data, which is primarily used for uploading files. It is written on top of busboy for maximum efficiency.
   `npm i multer`

2. devDependencies
   a. nodemon : `npm install --save-dev nodemon`
